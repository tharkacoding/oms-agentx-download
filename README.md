# Om's AgentX — Downloads

Public downloads for **Om's AgentX**, a Windows desktop agent with a visible
in-app browser and a terminal-AI bridge.

The source repository is private.

## Download

**[Download Om's AgentX v0.1.0 (Windows x64)](https://github.com/tharkacoding/oms-agentx-download/releases/latest/download/Oms-AgentX-win32-x64.zip)**

1. Download and extract the zip.
2. Keep the whole `Om's AgentX-win32-x64` folder together.
3. Run `Om's AgentX.exe`.

No installer, Node.js, npm, or Playwright is required. The app's browser is
Electron's built-in Chromium, so it works on a clean Windows machine. Chrome or
Edge is optional.

Windows SmartScreen may warn because the exe is unsigned: choose **More info →
Run anyway**.
